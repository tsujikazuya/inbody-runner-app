# StrideFuel

女子長距離選手向けの体組成改善サポート用プロトタイプです。

## 目的

InBodyで「体脂肪率が平均より高い」「骨格筋量が平均より低い」選手に対して、単純な減量ではなく、競技パフォーマンスと健康を守りながら改善行動を提示します。

## 主な機能

- InBody値、血液検査、走行距離、疲労、月経、骨ストレス既往、補食状況を入力
- 練習中の平均心拍、実施時間、消費カロリーを入力
- 今日の練習メニュー、開始時間、狙いの強度に応じた食事メニューと補給アドバイスを表示
- エネルギー、たんぱく質、鉄、骨、回復、体組成の栄養アプローチを表示
- 体調や練習内容に合わせた応援メッセージを表示
- 睡眠、食欲、痛み、気分、安静時心拍を使った体調管理
- BMI、脂肪量、除脂肪量、筋量/体重比を自動計算
- Hb、フェリチン、ビタミンD、CKの注意サインを表示
- 体脂肪・筋量・回復余力をバー表示
- RED-S/女性アスリート三主徴のサインを踏まえた安全アラート
- 今週の重点プランを自動生成
- 朝食・練習前・練習後・夕食のメニュー提案
- スマートフォンのカメラで食事写真を撮影し、食品グループの達成状況をチェック
- 練習内容、鉄、骨、筋量、補食状況に合わせたレシピ提案
- 印刷して選手・指導者・保護者・専門家と共有可能

食事写真はブラウザ上でプレビューし、外部サーバーへ送信しません。画像から栄養素を完全自動推定する機能は未実装で、食品グループのチェックと練習内容に応じたアドバイスで管理します。

## 開き方

`index.html` をブラウザで開くと動きます。ビルドやサーバーは不要です。

## 参考にした安全観点

- IOC 2023 REDs consensus statement: 低エネルギー利用可能性は健康・パフォーマンスに悪影響を与える可能性があり、月経、骨、代謝、心理、回復など複数の指標で見る必要があります。
- ACSM Female Athlete Triad position stand: 女性アスリート三主徴は、低エネルギー利用可能性、月経機能、骨密度が相互に関係するスペクトラムとして扱われます。
- InBody公式解説: 体組成測定は体重だけでなく骨格筋量、体脂肪量、体脂肪率などを合わせて評価します。単回測定ではなく条件をそろえて経時変化を見る設計にしています。

このプロトタイプは診断・治療を目的としません。月経停止、疲労骨折、急な体重減少、強い食事制限がある場合は、医師・管理栄養士・公認スポーツ栄養士などに相談してください。
